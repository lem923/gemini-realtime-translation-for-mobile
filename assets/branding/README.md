# Branding assets

`app_icon_master.png` is the source artwork for the Android and iOS launcher
icons and launch marks in this repository. The symbol combines two-way speech
bubbles, bidirectional arrows, and a voice waveform.

The artwork was generated specifically for this open-source project with
OpenAI image generation, then resized locally into platform asset catalogs. It
does not incorporate a third-party logo, flag, wordmark, or trademark.

When replacing the master, keep the subject inside the central safe area and
regenerate every Android density and every size listed in the iOS
`AppIcon.appiconset/Contents.json` file. iOS marketing icons must remain opaque.
